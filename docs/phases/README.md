# Development phases

Amma Wallet was built in seven phases between February and November 2026. Each file below summarises one phase: what it set out to do, what shipped, and what it left behind for later phases. Read them in order for the full story, or jump to the one you need.

| # | Phase | When | In one line |
|---|---|---|---|
| 1 | [Stellar MVP](01-stellar-mvp.md) | Feb to Jun 2026 | The first Stellar web wallet, API, tokens, DEX, fiat ramp and NFTs. |
| 2 | [July security audit](02-security-audit.md) | 25 to 29 Jul 2026 | 319 findings, all 14 critical issues fixed, tests added from scratch. |
| 3 | [Admin console, LMS and SSO](03-admin-lms-sso.md) | Jul to early Sep 2026 | Tenant admin and billing UI, NFT credentials, OAuth 2.1 provider for partners. |
| 4 | [Production audit](04-production-audit.md) | 1 to 2 Sep 2026 | Second audit across wallet and LMS; token hashing and SSO hardening. |
| 5 | [RBAC, billing and XRPL](05-rbac-billing-xrpl.md) | Oct 2026 | Financial-integrity audit, credit idempotency, LMS email onboarding, XRP testnet milestones. |
| 6 | [Interledger, Ethereum and the first autonomous release](06-interledger-ethereum.md) | 3 to 12 Nov 2026 | Open Payments, Ethereum Sepolia, guarded migrations, passphrases, mobile app builds. |
| 7 | [Managed custody and the wallet assessment](07-custody-assessment.md) | 13 Nov 2026 to now | Custody by default, mainnet switches and caps, the WA queue, PIN retirement, new CI. |

This is a snapshot for the Interledger hackathon judges, taken without git history. Internal plans, audit notes, runbooks and CI configuration are not included.
